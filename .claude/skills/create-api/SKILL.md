# Create API Workflow
 
1. Inspect the existing Python API structure and patterns.
2. Inspect the relevant models, schemas, and existing endpoints.
3. Create or update request and response schemas.
4. Add the new API endpoint.
5. Implement the required service or business logic.
6. Add input validation.
7. Add appropriate error handling and HTTP status codes.
8. Add unit and integration tests.
9. Run the relevant tests and verify that they pass.
10. Update API documentation or project documentation if required.
 
## Guidelines
 
- Follow the existing Python project architecture.
- Reuse existing utilities, dependencies, and patterns where possible.
- Do not introduce unnecessary dependencies.
- Follow the project's coding standards.
- Keep API routes/endpoints focused on request handling.
- Keep business logic in the appropriate service layer.
- Do not modify unrelated functionality.
